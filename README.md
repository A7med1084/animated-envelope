# 📩 Animated Envelope Card

A creative animated envelope built using HTML & CSS.  
When hovering over the envelope, it opens smoothly and reveals a card inside with a 3D effect.

---

## 🚀 Demo
👉 You can view the project live here:  
 https://a7med1084.github.io/animated-envelope/

---

## 🛠️ Technologies Used
- HTML5  
- CSS3 (Animations, Transforms, Perspective)

---

## ✨ Features
- Smooth hover animation  
- 3D perspective effect  
- Pure CSS animation (no libraries)  
- Clean and simple design  

---

## 💡 What I Learned
- How to use transform and perspective in CSS  
- Creating shapes using borders  
- Building animations with @keyframes  
- Improving UI interactions using hover effects
